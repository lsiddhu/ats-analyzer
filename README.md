# AI Resume Analyzer

An AI-powered web application that helps users check how well their resume matches a specific job description. It analyzes the resume and provides an ATS-style score, matching skills, missing keywords, and suggestions for improvement.

## Features

* User registration and login
* Resume PDF upload
* Resume text extraction
* Job description analysis
* AI-powered resume evaluation
* ATS score and keyword matching
* Missing skills and improvement suggestions
* Responsive dashboard
* Resume analysis history

## Tech Stack

**Frontend:** React.js, JavaScript, Tailwind CSS
**Backend:** Node.js, Express.js
**Database:** MongoDB, Mongoose
**AI:** Google Gemini API
**Authentication:** JWT

## How It Works

1. Create an account or log in.
2. Upload your resume in PDF format.
3. Enter the job description.
4. The application analyzes both using AI.
5. View your ATS score, matched skills, missing keywords, and suggestions.

## Setup

Clone the repository and install the dependencies:

```bash
git clone https://github.com/yourusername/ai-resume-analyzer.git
cd ai-resume-analyzer
npm install
```

Create a `.env` file with your MongoDB, JWT, and Gemini API credentials, then start the frontend and backend.
